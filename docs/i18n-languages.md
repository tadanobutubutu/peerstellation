# 言語カタログ

Peerstellationの言語選択は、`auto`（ブラウザー優先言語）に加えて、ISO 639-1の184言語タグと簡体字中国語の`zh-CN`を収録しています。設定画面の「Language coverage」を開くと、収録タグ・表示名・翻訳状態を全件確認できます。

> **品質境界:** 現時点で185タグの `nativeReview` はすべて `pending` です。母語話者の署名付き証跡がないため、どの言語も「完全に自然なネイティブ品質」とは保証していません。機械翻訳、橋渡し翻訳、LLMの評価、英語残存率は母語品質の証明にならないため、公開表示にも「native review required」を残しています。

## 翻訳状態

- 185タグすべてに、シェル、3Dシーンの説明、設定項目、操作方法、ピア詳細、状態通知、クレジット説明、翻訳率表示を含む197キーのロケールパックを用意しています。長尾パックは選択時だけ静的JSONを遅延取得し、取得後はセッション内でキャッシュします。各JSONには生成時の文字体系、`ltr`/`rtl`方向、英語原文と一致したキーの割合（`__residue`）を記録し、CLDRの既定値と実際の訳文が異なる言語でも表示方向を維持します。
- `en`, `ja`, `zh-CN`, `ko`, `es`, `fr`, `de`はリポジトリ内の編集済み製品文言ですが、母語話者の独立承認は未完了です。残りは生成済みの対象言語パックで、生成時にプレースホルダー、空文字、キー数を検証します。翻訳サービスが直接対応するタグは原語タグへ直接生成し、直接コーパスがない29タグだけ橋渡し言語を使います。
- 低リソース言語や翻訳サービスが対応しないタグ（例: `ae`, `cr`, `ho`）は、近縁または実用上の橋渡し言語で生成した暫定パックです。タグと`<html lang>`は要求言語を維持しますが、公開前に母語話者レビューを行う対象としてマニフェストで追跡します。これは「英語フォールバック」を翻訳済みと偽装しないための明示的な品質境界です。
- Credits and licensesでは、ライセンス名・作者名・作品名などの法的識別子は原表記を維持し、説明文とリンクラベルは選択言語へ切り替えます。

## 再生成と品質ゲート

`npm run i18n:generate` は開発時だけ実行する生成コマンドです。Google Translateの公開エンドポイントへ英語の197キーを一括送信し、結果を `public/locales/<tag>.json` と `public/locales/manifest.json` に保存します。アプリの実行時に外部翻訳サービスへ接続することはありません。生成後のパックはリポジトリに同梱され、実行時にJSONの型・キー数・空文字・方向・残存率メタデータを再検証します。`__residue` は翻訳サービスが英語原文を変更しなかった割合であり、自然さや母語話者品質を保証する値ではありません。設定画面ではこの値から算出した実測翻訳率を表示します。

### 母語レビュー承認ゲート

`src/i18n/locale-provenance.ts` の `NATIVE_REVIEW_RECORDS` は意図的に空です。言語を `approved` にするには、対象言語の母語話者または専門翻訳者が、用語・文法・トーン・文字方向・複数形と数値・スクリーンリーダー文脈の全項目を確認し、レビュー日時、対象ソースのSHA-256、レビュー記録のパスまたはURLを同時に登録する必要があります。型検査と単体テストは、証跡のない言語を承認済みとして扱う変更を失敗させます。これらの証跡が揃うまで、185言語について完全なネイティブ品質を保証することはできません。

生成器が橋渡しを使うタグは `ae`, `an`, `bi`, `cr`, `cu`, `ho`, `hz`, `ie`, `ik`, `ii`, `io`, `ia`, `ki`, `kj`, `ks`, `kw`, `lu`, `na`, `nn`, `nd`, `ng`, `nv`, `oj`, `pi`, `rm`, `sc`, `vo`, `wa`, `za`です。これらは言語タグを変換せず、母語話者校閲が完了するまで暫定扱いにします。`aa`, `ab`, `av`, `bh`, `ce`, `iu`, `jv`, `kr`, `kv`, `mh`, `os`, `se`, `ty`, `ve`は翻訳サービスの直接出力へ昇格しています。
